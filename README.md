# Task Delay Risk Predictor

A machine-learning tool that rates open project tasks as **Low, Medium or High delay risk**, so the project manager gets an early warning before a task slips. The ratings are shown in Jira.

MAI 104 – Group 10

## Repository structure

| Folder | Contents |
| --- | --- |
| `data/` | Synthetic task datasets (one file per version) |
| `notebooks/` | Google Colab notebooks: data generation, models and evaluation |
| `outputs/` | Model results, the ratings file imported into Jira, and figures |
| `docs/` | Data documentation and the rule-of-thumb risk checklist |

## How to run

Open a notebook from `notebooks/` in Google Colab (**File → Open notebook → GitHub**) and run the cells in order.
